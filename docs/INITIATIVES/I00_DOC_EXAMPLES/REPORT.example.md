## Decisions

**Dual-purpose structure:** Use I00 as both reference and example
*Reasoning:* More valuable to show real work that actually happened vs synthetic examples

**Template vs executable distinction:** Use .example.md for references, .md for actual initiatives
*Reasoning:* Clear separation between learning materials and work-to-be-done

**Comprehensive guidance approach:** Provide detailed guides rather than minimal examples
*Reasoning:* Users and agents need rich context to produce quality documentation
