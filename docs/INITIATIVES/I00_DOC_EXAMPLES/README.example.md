# I00 — Initiative Template Examples & Documentation Patterns

**Purpose:** This contains template examples and writing guides for initiative documentation. These are **reference materials for learning** - not work to be executed.

**⚠️ Important:** This is I00 (template examples). Your actual first initiative is **I0 - Adopt Mode** which stabilizes your codebase and adds Supabase integration.

---

## What this demonstrates

**How to write effective initiative documentation:**
- Clear outcome statements that define end state
- Scope vs Non-scope boundaries  
- Testable acceptance criteria
- Task breakdown with completion tracking
- Decision logging with reasoning
- Risk identification and mitigation  
- Progress narrative structure

**Real example included:**
This directory includes the actual Initiative I0 that created this core's template system - demonstrating how to execute initiatives systematically.

## Learning objectives
After reviewing these templates, users and agents should understand:
- How to write clear, actionable scope statements
- The difference between outcome (end state) and scope (deliverables)  
- How to use acceptance criteria as completion gates
- When and how to log decisions vs risks vs progress
- Best practices for initiative planning and execution
