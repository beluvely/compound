# I4 — Brand Logo

**A basic, clear logo system for Compound**

---

## Outcome

A simple, recognizable logo that represents Compound's identity as a document-first knowledge workspace where understanding compounds over time. The logo system includes all necessary variants and assets for immediate use in the application and documentation.

## Scope

### In-scope
- Logo concept exploration aligned with product principles
- SVG assets for web use:
  - Icon/mark (standalone symbol)
  - Wordmark (text-based)
  - Full logo (icon + wordmark)
- Logo variants:
  - Grayscale/neutral (primary)
  - Dark mode version
  - Monochrome (single color)
- Favicon generation (multiple sizes)
- Integration in application UI (header/nav)
- Basic usage guidelines document

### Explicitly out-of-scope (for I4)
- Full brand identity system
- Complete color palette development
- Typography system
- Marketing collateral or templates
- Animated logo variants
- Complex illustration system
- Print-specific formats

## Acceptance criteria

- [ ] Logo concept approved that visually expresses "knowledge compounding over time"
- [ ] SVG assets created and optimized (icon, wordmark, full logo)
- [ ] Favicon files generated for all required sizes
- [ ] Logo integrated in application header/navigation
- [ ] Basic usage guidelines documented (when to use which variant)
- [ ] Logo files organized in `/public` with clear naming convention
- [ ] Dark mode variant tested and working

## Design principles alignment

The logo should reflect Compound's core identity:

* **Document-first** — suggest structure, addressability, interconnection
* **Compounding knowledge** — visual metaphor for growth/accumulation over time
* **Calm clarity** — not polished corporate, not playful startup
* **Editor-first** — feels at home in a writing/thinking environment
* **Local-first** — solid, stable, trustworthy

Avoid:
* Generic geometric shapes without meaning
* Overly complex or illustrative marks
* Trendy effects that won't age well
* Corporate gradient treatments
* Cutesy or playful aesthetics

## Vocabulary notes

* **Icon/Mark** — the standalone graphic symbol
* **Wordmark** — the text treatment of "Compound"
* **Full logo** — icon + wordmark combined
* **Lockup** — a specific arrangement of logo elements

Use these terms consistently in design files and documentation.
